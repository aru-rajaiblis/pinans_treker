# Task 1: Environment Exploration & Tech Stack Initialization

**Context:** The backend bot and Supabase database are already functional. We need to initialize the Next.js frontend without breaking the current backend structure.

**Objective:** Create and configure the Next.js project template.

**Requirements:**

*   Inspect the workspace directory. If suitable, initialize a Next.js (App Router, TypeScript, Tailwind CSS) project (either in the root or a `/frontend` directory, depending on the workspace structure).
*   Install UI dependencies: `shadcn/ui` and `tremor` (or `@tremor/react`) for financial charts.
*   Configure Tailwind CSS to ensure Tremor and Shadcn styles do not conflict.
*   Run the development server (`npm run dev`) and ensure it compiles with zero errors.

**Definition of Done (DoD):** Next.js home page is accessible on `localhost:3000` with Shadcn and Tremor libraries successfully installed and verified.
